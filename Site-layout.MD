### 🎨 What You Can Do Inside the Maps

* 📈 **Trace Melodic Contours:** Every chapter page contains a color-coded visual map tracking shapes and recurring phrases. 
* 🔊 **Listen directly:** Click any row or individual verse to activate audio playback based on original *te'amim* accents.
* 🧮 **Examine the Math:** Use the embedded toggles to overlay word weights and prime factors across the ornament chapter pages.
* 🎼 **Download Assets:** Music scores are available inside each directory as universal `.xml` trees or native Musescore `.mscz` files.

### Underlying Data Trace
The base JSON files originate from a trace included in a custom Unicode to MusicXML program written c. 2013. It spans over **730,000 rows**—representing one row for every single syllable in the Tanach. Supplementary responsive JSON files handle the text mapping, English guidance overlays, and display responsiveness.

### Bulk Data Exports
If you require raw data blocks or verification logs for local analysis, they are preserved inside the `/developer_tools` repository directory:
* `MUSICSTATS.xlsx` (Excel Spreadsheet format)
* `MUSICSTATS.csv` (Comma Separated Values)
* Historical system verification logbooks

### Technical Contributions
The ancient musicians spent years in rigorous schooling to master this architecture. Today, AI can assist you in generating Python, HTML, Javascript, or manipulating `.mscz` files. If you require a custom view of this dataset, you are welcome to pull the repository down to your local machine and adapt it.
