Music Scores by Canonical Volume

Select a volume link below to explore the underlying musical assets. The music scores are systematically catalogued across two distinct formats: .mscz files created in Musescore, and universal .xml trees for use by other music programs.

Each directory containsa high-density, color-coded visual map tracking the melodic contours and shapes of each chapter—allowing you to inspect the architecture of the music at a glance.

In the contour map, you can highlight a motif and search for it in the rest of the canonical text. Click a row to see recurring phrases in the chapter and to engage the search button in the navigation block for wider distribution of the motif. Motifs are mapped from 3 to 5.The motif matrix form will truncate longer search strings. On the Musical Motif Concordance pages, you can manually type in the note sequence you wish to search for and press the Search Motif button.

Ornaments by recitation note gives us an ornament concordance by reciting note and ornament with filtering by book and toggle of niqqud to help learn the cantillation signs.

There is a rather large file containing all the shapes of phrases, approaching the atnah, and returning to the tonic, and verses without a subdominant. You can search by hand in this file using your browser search facility.

The base json files come from a trace I included in the Unicode to MusicXML program written c 2013. It has over 730,000 rows, at least one row for every syllable in Tanach. It does not have rows for the very small number of syllables with two sublinear accents under one letter, fewer than 20 in 730,000, most but not all in the decalogues. The JSON trace files do not reflect the second sublinear accent. They are evident in the music or the Hebrew that accompanies it. Additional json files have been generated to support the Hebrew, the English guide, and the responsiveness of the interactive displays.

The latest release of Musescore allows creation of MP4 files. A limited nuber of these and other links to performances on the web will appear on this site under the directory VideoPlus.

All these tools allow us to see, hear, and imagine what musical language the text requires as seen by the originators of the te'amim. Please note that if there is some view of the data you wish to see, you can ask me, or you can pull the repository to your local machine and begin to learn its possibilities. AI can write Python, HTML, and Javascript and manipulate mscz files if you can specify what you want. The ancient musicians had a large school of music and many years of training (and no snakes writing software).
