Music Scores by Canonical Volume

Select a volume link below to explore the underlying musical assets. The music scores are systematically catalogued across two distinct formats: .mscz files optimized for direct manipulation in MuseScore, and universal .xml trees for compatibility across alternative notation software suites.

Each directory contains its own optimized JSON structure and a high-density, color-coded visual map tracking the exact melodic contours and shapes of each chapter—allowing you to inspect the architectural architecture of the music at a glance.

Volume Directory Status Notice: All text divisions are cross-verified for structural accuracy. If you require the master analytical data spreadsheets (MUSICSTATS.xlsx or .csv) or old system verification logs, please consult the newly isolated /developer_tools directory.

From the JSON files, there is a rather large file containing all the shapes of phrases, approaching the atnah, and returning to the tonic, and verses without a subdominant. These allow us to see and imagine what musical language the text requires as seen by the originators of the te'amim. The file comes from a trace I included in the Unicode to MusicXML program written c 2013. The trace has over 730,000 rows, at least one row for every accented letter in Tanach. It does not have rows for the very small number of syllables with two sublinear accents under one letter, fewer than 140 in 730,000. The JSON trace files do not reflect the second sublinear accent. I'll find out the total, but it is a tricky problem.
